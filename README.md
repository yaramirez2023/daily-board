# Construction Daily Board (I & II)

A self-contained, offline projector/reference board for Garey HS Construction I & II.
Shows each school day's bellringers, daily slide reading + comprehension questions, and
activities for the full year. No accounts, no external services — one static HTML page.

Live site: enabled via GitHub Pages (see repo Settings → Pages).
Rebuilt from `Bellringer-Board/slide-reading-board.html`; replace `index.html` and push to update.
